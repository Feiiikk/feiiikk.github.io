# Wellness Tracker 公共版

首次打开显示空白记录。此站已配置原有的云同步服务。使用原账号登录即可连接。若要自行发布公共模板，请使用空白的 config.js 并验证自己的行级权限。

训练页可重复上次训练，查看最近动作，点开一行填写。空白负重记为自重，时长和辅助重量仍各按实际字段填写。饮食页顶部可选择餐次并录入。食物选择器优先显示我的食物，再显示最近记录。自定义食物可一键记入当天并收藏。

## 多人账号与数据库

前端工作区隔离不能代替服务端权限。supabase-account-isolation.sql 是待你审阅、在自己项目执行的 RLS 配置：限制未登录访问，用户只能读写 auth.uid() 对应自己的行。包含 restrictive 策略，约束可能已有的宽松 permissive 策略。脚本未执行，现有线上 RLS 未经验证。

启用公开账号前，请在项目中执行并检查策略，用两个测试账号验证互相不能读取／覆盖数据。邮件注册还取决于 Supabase 的 Email provider、URL允许列表、发信配置和限额；默认发信服务可能不适合公众注册，需要配置合适的SMTP。注册按钮不会在首次打开时自动发送邮件。

https://supabase.com/docs/guides/database/postgres/row-level-security

## 自动识别

Training 顶部展开“识别训练日志：文字／截图”。

文字：每行一个动作，粘贴后点“解析文字”。支持中英文名称、kg/lb、3×12、12×3（会提示核对）、明确的组数／次数、有氧分钟、超级组标记和单日日期。无法精确匹配的动作作为自定义动作保留，不猜动作视频或缺失重量。一次只解析一天，多个日期会阻止填入。

截图：选择PNG/JPEG/WebP截图，浏览器内运行 Tesseract.js 中英文 OCR。引擎和模型随本包部署到同一个站点，图片不发送到识别服务；无需 AI API 密钥。首次使用要下载约十几MB的运行组件和模型，随后可缓存使用。设备速度、字体和清晰度会影响结果，低内存设备可能无法完成；可改用iPhone照片的“实况文本”复制文字后粘贴。

识别结果先出现在可编辑预览，可以改动作、重量、组次、超级组、备注和日期；确认后追加到训练草稿，现有动作不直接覆盖，再点“保存训练”才写入记录。原截图和完整识别原文不保存到云端；最终确认保存的训练字段沿用原本同步流程。若配对动作、重量口径或次数不明确，须自行核对。

https://github.com/naptha/tesseract.js

## 分类条

分类支持iPhone原生左右滑动以及鼠标拖动；“全部分类”可展开为网格，直接选择末尾分类。选择分类后恢复横向条。按键可聚焦，分类按钮为标准按钮。

## 部署

将解压后的文件放到静态网站目录。公开模板的 config.js 留空，可部署到新的仓库。应用不含内置的个人资料、账号邮箱或历史训练。以此包创建新仓库只会给新项目一个干净的起点。原仓库历史应单独处理。
